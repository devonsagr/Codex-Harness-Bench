# 社区实践小项目

8 个不同机制的离线项目：旋转墙碰撞、三维轨道、分形、排序、寻路、落块、贪吃蛇、生命游戏。题面和固定接口见 `catalog.json`，77 个功能核心用例见 `tests/cases.json`。本项目重新编写需求和验收，没有复制上游代码或参考答案；主题出处列在每题 `referenceUrl`。

启动工作台会补入缺失题目，不覆盖已编辑或已归档的版本。被测工作区只有空白 `index.html` 与 `model.js`，参考实现不进入起点。回收后点“运行程序检查”，首次检查自动准备可信镜像；在禁网容器副本执行，宿主快照只读。

- 功能核心检查：逐个固定输入、预期输出与输入不变性；超时和缺失证据不缩小分母。
- 页面检查：真实 Chromium 点击开始、暂停、重置，观察声明状态、核心调用、390/768/1280 视口溢出和脚本异常。
- 视觉、完整游戏流程、连续碰撞和用户体验另需实际运行取证，不能用核心通过百分比替代。页面检查也不证明所有场景语义正确。

这些是 CHB 原创改编题，采用项目 MIT 许可；不是上游官方题包或排行榜成绩。核心比例只解释本题固定用例。同模型 Harness 对照必须保持题目、程序协议和环境一致，并同时看失败、未知、资源与人工介入。
