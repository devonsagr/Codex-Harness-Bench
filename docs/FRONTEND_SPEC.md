# 前端与交互合同

当前基于用户提供的 Gemini React/TypeScript/Vite/Tailwind 前端。输入目录只读，工程副本在 frontend/。本轮接入功能与修复影响操作的问题，保留浅色/炭黑主题、字体切换、导航、主从卡片和过渡语言；全面减法设计留待后续用户审阅。

## 页面职责

|页面|实际动作|关键状态|
|---|---|---|
|评测工作台|默认单配置单题、可选两套/批量、冻结策略、准备工作区；运行详情串联桌面执行与验收|空配置/未选题、未启动、每轮等待确认、工作中、回收、后台检查、异常、结束|
|配置管理|真实版本编辑、另存、部分导入全局、显式技能目录导入与勾选、个人约束|过期写入错误、文件导入失败、版本号与技能摘要|
|题库中心|项目构建/Bug 分类、搜索、需求编辑、多轮、起点导入、逐项容器检查、来源说明|题面不等于可执行基准；没有检查不编造 npm test|
|评测历史|当时配置、题目、快照、复审、导出、归档/恢复|无历史、进行中、异常、归档只读；恢复配置生成新副本|
|同条件结果|证据与条件齐备的记录分组|不自动预设排名，证据不足仍保留历史|
|原理与规范|完整操作流、三类证据、公式与适用范围|不把项目背景塞成用户必须反复阅读的口号|

## 数据与组件

- App.tsx：主题、页面选择、后端请求状态与后台任务轮询。浏览器只保存外观偏好，不保存业务数据。服务断开显示错误，无模拟数据兜底。
- workbench/api.ts：同源 GET/POST 与令牌、错误、ZIP 下载。
- workbench/Runner.tsx：准备表单、运行主从页、阶段操作、文件和证据、人工复审。
- workbench/Editors.tsx：配置/题目表单与明确目录导入。
- workbench/Records.tsx：历史、同条件分组、说明。
- workbench/types.ts：真实接口的数据合同；不存在随机结果类型。
- components/ArenaHeader.tsx、index.css：承接 Gemini 的主题和视觉基础。

原型 services/arenaStore.ts 的模拟执行、虚构 launcher、默认评分等不进入实际编译链。原副本保存在 .local/sources/gemini-ui-retired，用户源仓库未改；需要回看设计时按私有来源回执定位。

## 必须维持的交互约束

1. 工作区准备不等于执行。打开桌面、复制提示词、记录开始是不同动作；不得假装桌面已经收到提示词。
2. 阶段提示词与当前阶段紧邻显示，继续必须明确确认；不弹无关联的巨型浮层。小屏按配置→题目→准备显示。
3. 回收显示精确工作区和快照版本，保留新增/删除/修改事实；旧文件不改写，不用当前配置悄悄替换；允许选取已有快照补做检查，新检查记录与旧结果分存。
4. 未执行、失败、环境错误、超时、取消和额度中断分开。按钮文字“停止后台检查”不能用于桌面任务。
5. AI 审查明确提示会使用模型额度；结果为带引用的意见。没有视觉证据不能自动声称美观验收完成。
6. 人工评分初值为空，0–100 支持小数；显示适用维度、依据、可用程度及个人约束。提交产生新版本。
7. 分数/Token/时长未知显示“—”；界面旁解释所缺证据。缓存属于输入。无凭空 IQ、误差范围或费用。
8. 错误使用可见 alert；后台操作显示实际状态并轮询。失败保留用户输入，过期写入不自动覆盖。
9. 所有输入有标签；键盘焦点可见；小屏无横向溢出；尊重减少动态效果设置。
10. 导出按钮明确含记录与产物。包可能有私有规则，不自动公开；归档不永久删除。

## 验收依据

构建 `pnpm --dir frontend build`，功能用 http://127.0.0.1:8765 同源服务。必须实际走自定义题保存、单配置准备、逐轮回收、人工评分、历史恢复；不能以 TypeScript 通过代替操作验收。当前状态由 PROJECT_SPEC.md 与 当前交接.md 统一维护。
