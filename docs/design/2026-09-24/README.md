## 生成方式与提示词

两张图均由内置 `image_gen` 生成，最终文件保存于本目录，没有通过外部 API 或安装新的 Codex 技能。以下是交付用的规范化提示词；绘制的文字只需表达信息层级，网页中的中文必须由代码准确实现。

- `generated-direction-01.png`：为「Codex 桌面 Harness＋模型评测工作台」制作完整桌面网页画面。采用温暖纸张和杂志式编辑排版、适量留白、较强的中文标题层级；展示评测准备、已有工程题目索引、源码起点与任务详情。避免密集 KPI 卡片与一长列说明文字。只作 UI 视觉参考，不冒充可运行产品截图。
- `generated-direction-02.png`：为同一产品制作另一张完整桌面网页画面。采用研究仪表台方向：深石墨色左侧导航、浅矿物色主画布、荧光绿的单一主操作、醒目的中文衬线标题与清晰的无衬线正文、细线网格和编号。主区域一眼读出「选择真实任务 → 核对固定源码与环境 → 创建独立工作区」，将任务索引与右侧详情并排，避免纯换色或卡片堆叠。只作构图参考。

项目中只采用一种外部开源材料做排版研究：[GC Minimal Zine Poster](https://github.com/LiamGvchi/gc-minimal-zine-poster)（MIT）。研究副本集中在项目忽略目录 `.local/frontend-references/2026-09-24/gc-minimal-zine-poster/`，不会进入用户全局技能目录，也没有把对方图像或代码直接嵌进网站。原始提交 `ddb0d66b24a94f9c4fdd1f02835a836a2db3774e`。`photo-abstract-editorial` 由于许可不适合当前公开项目，没有安装或取用素材。网站线框装饰是项目自绘 SVG。

字体 `Noto Sans SC`、`Noto Serif SC` 自托管在 `frontend/public/fonts/`，遵循各自随附的 OFL 许可。标题字库只保留当前界面实际字符，正文保留常用中文范围；缺字时交给系统后备字体。页面不请求外部字体 CDN。
