## 风险

当前有三个声明任务组，搜索与存储有共同笔记工程背景，组名不能当作统计独立性的证明；不输出置信区间或总排名。旧实验的配置、执行代码、任务与时间不同，不能直接合并计算配置收益。配置生效只能观察公开接口和日志，不可能完整证明模型内部行为。此前存储题观察到显式读取 skill，CSV 题未观察到完整读取，不能由单题推断触发概率。本次模型服务实际返回工作区额度不足，真实全批验收尚未完成；额度状态是外部条件。Docker 曾出现标签列得出但无法解析、内容 ID 仍可访问的状态；本轮按已验证的精确 ID 重建标签，没有重建镜像或改变旧计划。镜像保留不能保证跨机复现。用量计数核验只支持已验证的 Codex 0.154.0 协议，费用依然不提供账单估值。
